# Учебная платформа (React)

Проект выполнен на стандартном React без использования сторонних библиотек (роутинг реализован через useState).

## Как запустить проект:
1. Установите зависимости: `npm install`
2. Запустите сервер: `npm run dev`
3. Откройте в браузере: `http://localhost:5173/`

## Реализованный функционал:
- Переключение страниц без перезагрузки (SPA).
- Вывод списка партнеров и лекторов.
- Бонусное задание: фотографии лекторов загружаются из внешнего облачного хранилища (ImgBB).
